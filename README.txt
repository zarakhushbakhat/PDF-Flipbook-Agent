YOUR FLIPBOOK
CLIENT PACKAGE

Thank you for your order. This ZIP contains a ready-to-open,
standalone flipbook made from your PDF.


WHAT IS INCLUDED

- flipbook/index.html: open this file to view the flipbook
- flipbook/css/: viewer styles
- flipbook/js/: flipbook scripts and required libraries
- flipbook/pages/: rendered PDF page images
- flipbook/assets/: page-turn sound and any saved branding images


HOW TO OPEN

1. Extract the ZIP file.
2. Open the flipbook folder.
3. Double-click index.html.

Keep the files and folders inside flipbook together in their
original locations. The package does not require Python or
programming software.


WHAT YOU RECEIVE

Your finished output is an interactive digital flipbook created
from your PDF. The ZIP includes the flipbook and the files it
needs to display the pages; clients do not need to install
Python or other programming software.


FEATURES YOUR CLIENTS CAN USE

- Realistic animated page turning
- Previous, next, first, and last page navigation
- Page number indicator
- Page thumbnails in a sidebar that can be opened, closed, and
  resized by dragging its edge
- Search within PDF text, including English text recognized from
  scanned pages during flipbook generation
- Zoom and fullscreen controls
- Keyboard, mouse, and touch navigation
- A responsive layout for phones, tablets, and desktop computers

The downloaded viewer is delivered as a finished flipbook and
does not include the online Customize button or customization
panel.


PUT THE FLIPBOOK ON A WEBSITE

Upload the complete flipbook folder to your web hosting without
changing its structure. For example:

your-website/
  flipbook/
    index.html
    css/
    js/
    pages/
    assets/

The hosted flipbook can then be shared using its web address or
embedded in another page with an iframe.

Opening index.html locally works in modern browsers. Some browser
features may be restricted when opened directly from a computer;
if so, upload the complete folder to a web server.


IMPORTANT

The ZIP contains rendered page images and supporting files, not
the original PDF. Search text is prepared when the flipbook is
generated, so clients do not need to install OCR software.
