5. HOW TO PUT THE FLIPBOOK ON YOUR WEBSITE
------------------------------------------------------------

If you have website hosting, you can upload the complete
flipbook files to your website.

Upload:

- index.html
- css/
- js/
- images/


Keep the same folder structure.

For example:

your-website/
│
└── flipbook/
    ├── index.html
    ├── css/
    ├── js/
    └── images/


After uploading, your flipbook can be accessed using a URL
similar to:

https://yourwebsite.com/flipbook/


------------------------------------------------------------
6. HOW TO EMBED THE FLIPBOOK
------------------------------------------------------------

If you want to display the flipbook inside another webpage,
you can embed its web address using an iframe.

Example:

<iframe
    src="https://yourwebsite.com/flipbook/"
    width="100%"
    height="700"
    frameborder="0"
    allowfullscreen>
</iframe>


Replace the example URL with the actual URL where your
flipbook is hosted.
